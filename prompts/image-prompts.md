# image-prompts.md — placeholder

El sitio actualmente no usa fotografía de terceros ni imágenes generadas:
todo el contenido visual es SVG inline (marca "+V", iconos de servicio,
iconos de redes sociales) para evitar dependencias externas y mantener el
sitio 100% estático y ligero.

Si en un segmento futuro se decide incorporar fotografía (p. ej. equipo,
oficinas, casos de éxito), documentar aquí:

- Prompt exacto usado (si es imagen generada) o fuente/licencia (si es
  fotografía real/stock).
- Dimensiones y formato de exportación (`webp` preferido, con fallback).
- Ruta de destino en `assets/images/`.

Recordatorio: no usar logotipos reales de clientes (Invex, Iberdrola/Cox,
ADITMEX, Dentool, CashClick) sin autorización explícita — usar tratamiento
tipográfico en texto hasta contar con permiso y archivo de logo oficial.
